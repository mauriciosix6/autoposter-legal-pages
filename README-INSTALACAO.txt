AUTPOSTER GG - MINI SERVIDOR DE TERMOS E PRIVACIDADE

Arquivos:
- package.json
- server.js

Como testar no PC:
1. Abra o terminal na pasta autoposter-legal-pages
2. Rode: npm install
3. Rode: npm start
4. Abra no navegador:
   http://localhost:3000/terms
   http://localhost:3000/privacy

Como subir no Railway:
1. Crie um repositório no GitHub com estes arquivos
2. No Railway clique em New
3. Deploy from GitHub repo
4. Selecione o repositório
5. Depois vá em Settings / Networking / Generate Domain
